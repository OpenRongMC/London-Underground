# 伦敦地铁扩展

简体中文 · [English](./README.en.md)


伦敦地铁扩展由 t1NbLu3 开发，用来搭建伦敦地铁风格的车站和隧道。车站构件包括白色与混凝土站台砖、楼梯、隧道线缆以及不同样式的标识。创造栏按车站与隧道构件、标识和旧方块分组。

## RongMC 26.3 版本的改动

本版适配 Minecraft 26.3 的方块、物品或列车资源加载，并改用配套 MTR 4.0.5 的接口。扩展已有的主题和玩法沿用上游。

## 安装

在 [GitHub Releases](https://github.com/OpenRongMC/London-Underground/releases/tag/v2.2.4-port.1%2B26.3) 下载 **v2.2.4-port.1+26.3**。使用 Minecraft Java **26.3**、**Fabric** 和 **Java 25**。 依赖 [Fabric API](https://modrinth.com/mod/fabric-api)、[MTR](https://github.com/OpenRongMC/Minecraft-Transit-Railway)。 将发行 JAR 放进实例的 `mods/` 目录。 与同系列 RongMC MTR 一起装到客户端和服务端。自定义列车资源包也要在实际使用的客户端启用。
